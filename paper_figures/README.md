Regenerate Figs. 2–3 with `MTIL_DATA=<data root> python test/make_figs_ral_pgf.py` (`FIG_OUT` sets the output
directory). All three use one editorial palette (ink, muted, soft, one accent for the focal element) and need this
preamble in an IEEE `ieeeconf` document:

```latex
\usepackage{xcolor,tikz,pgfplots}\pgfplotsset{compat=1.17}
\usetikzlibrary{arrows.meta,positioning,calc}
\usepackage[scaled=0.9]{helvet}
\usepackage{sansmath,textcomp}
\newcommand{\code}[1]{\texttt{\small #1}}
\definecolor{ddink}{HTML}{2D3142}\definecolor{ddmuted}{HTML}{4F5D75}\definecolor{ddsoft}{HTML}{5A6580}
\definecolor{ddaccent}{HTML}{BF4520}\definecolor{ddrule}{HTML}{BFC0C0}
```
